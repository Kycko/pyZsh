# Структура проекта

```
pyZsh
│
├─┬─> bin – самостоятельные скрипты-программы
│ │
│ ├─> exec        – исполняемые файлы (сами скрипты)
│ ├─> lib/pzexec  – библиотеки С КОРНЕМ pzexec
│ ├─> suggestions – дополнения для zsh
│ └─> init.py     – ВХОДНАЯ ТОЧКА во все скрипты
│
└─┬─> zshconf – скрипты инициализации zsh (его настройки)
  │
  ├─┬─> python – python-часть
  │ │
  │ ├─> lib/zshconf - библиотеки С КОРНЕМ zshconf
  │ ├─> 01_basicLoads.py
  │ ├─> 10_hotkeys.py
  │ └─> ...
  │
  ├─┬─> zsh – zsh-часть
  │ │
  │ ├─> 10_hotkeys.zsh
  │ ├─> 30_prompt.zsh
  │ └─> ...
  │
  ├─> init.py – запускается из .zshrc, выполняет python-часть
  └─> .zshrc  – ВХОДНАЯ ТОЧКА настроек zsh
```
